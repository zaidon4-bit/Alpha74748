Alpha — تقرير إضافة الميزات الأربع
===================================

تمت إضافة الميزات الأربع المحددة إلى نسخة AlphaX المدمجة، دون إزالة أي مدخل من الحزمة السابقة.

1) Smart Code Diff
- تقارن ملفات الخطة المولدة بمحتوى الملفات الأصلية المقروء من المرفقات.
- تعرض الملفات المعدلة والجديدة والمتطابقة، وتوضح الحالات التي تعذر فيها توفر نسخة أصلية للمقارنة.
- يمكن استبعاد أي ملف من حزمة التنزيل عبر إلغاء Include in accepted ZIP.
- التنزيل يجمع الملفات المقبولة فقط في ZIP منفصل؛ لا يتم تعديل ملفات المصدر المرفوعة أو مستودع Git تلقائياً.

2) Auto Test & Repair
- يجري فحصاً ساكناً للملفات المدعومة: صياغة Python، وبنية JSON، وتحليل HTML.
- عند وجود أخطاء ساكنة، يسمح بمحاولة إصلاح واحدة محدودة من الكاتب، ثم يعيد الفحص.
- لا يشغل أو يستورد أي كود يرفعه المستخدم أو يولده النموذج.
- ملفات JavaScript/TypeScript وCSS وغيرها غير المدعومة بهذا الفاحص تظهر ضمن الملفات المستثناة أو لا تدخل في عداد الفحوصات؛ لا تعتبرها ناجحة لمجرد عدم ظهور أخطاء.

3) Project Understanding
- يفهرس هيكل ZIP والملفات المدعومة ونقاط الدخول المحتملة.
- يستخرج أسماء دوال وكلاسات واستيرادات Python، واستيرادات JavaScript/TypeScript النسبية المحتملة.
- يستخرج أسماء الاعتماديات من package.json وملفات requirements دون عرض الإصدارات أو أسرار الإعداد.
- التحليل ساكن وتقريبي، ولا يثبت أن العلاقات المكتشفة تمثل كل علاقات التشغيل الفعلية.

4) Project Memory
- ذاكرة منفصلة لكل مستخدم ومفتاح مشروع.
- تحفظ ملخصات المهام الأخيرة ومسارات الملفات وملخص خريطة المشروع ونتائج الفحص.
- يمكن اختيار مشروع محفوظ من القائمة لمتابعة سياقه.
- لا تحفظ ذاكرة المشروع محتويات ملفات المصدر؛ وتزيل أنماطاً شائعة لمفاتيح API وكلمات المرور والرموز من حقول النص القصيرة قبل التخزين. هذا تقليل للمخاطر وليس ضماناً لاكتشاف كل سر محتمل.
- إن لم تسمّ المشروع، تستخدم Alpha تسمية عامة أو تستنتج الاسم من أول ملف مرفق؛ من الأفضل تسمية كل مشروع بوضوح لتجنب جمع أعمال غير مرتبطة في ذاكرة واحدة.

التحقق
------
- اختبارات Python: 56 ناجحاً، مع 13 حالة فرعية ناجحة.
- py_compile لملفات app.py وproject_intelligence.py وalpha_workspace.py: ناجح.
- node --check للسكريبت الرئيسي بعد استبدال قيم قوالب Jinja بقيم اختبار: ناجح.
- لم يتم تشغيل خادم Flask أو الاتصال الفعلي بمزودي النماذج في بيئة الفحص.

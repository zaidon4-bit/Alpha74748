Alpha AI — المرحلة الأولى: تشفير مفاتيح API بـ AES-256-GCM

النطاق:
- إضافة وحدة مستقلة secret_crypto.py.
- تشفير مفاتيح API الجديدة باستخدام AES-256-GCM من مكتبة cryptography الموثوقة.
- توليد nonce عشوائي جديد بطول 96 بت لكل عملية تشفير.
- اشتقاق مفتاح AES مستقل بطول 256 بت باستخدام HKDF-SHA256 من مادة مفتاح التشفير الحالية.
- ربط بيانات المصادقة AAD بسياق مفاتيح API الخاصة بـ Alpha.
- دعم فك تشفير سجلات Fernet القديمة دون تغييرها أو ترحيلها أو حذفها.
- كل مفاتيح API الجديدة التي تُحفظ عبر مسارات الإدارة تستخدم الصيغة ذات الإصدار a256gcm:v1.

المحافظة على البيانات والسلوك:
- لا تعديل على مخطط قاعدة البيانات.
- لا حذف أو تحديث تلقائي للسجلات الموجودة.
- لا تغيير في أسماء الحقول أو إعدادات Render أو Supabase.
- لا تغيير في واجهات المستخدم أو مسارات API أو منطق المحادثات.
- لم تتم إضافة TCP/C2 أو تنفيذ أوامر نظام عن بعد أو آليات تشغيل تلقائي مخفية.
- بقي requirements.txt كما هو؛ cryptography موجودة مسبقاً.

التحقق:
- الاختبارات المضافة: round-trip، nonce مختلف لكل تشفير، قراءة Fernet القديم، كشف العبث بالوسم، ورفض المفتاح الخاطئ.
- فحوصات التشغيل/الدمج الحي مع Supabase وRender ومزودي API لم تُنفذ في هذه البيئة.

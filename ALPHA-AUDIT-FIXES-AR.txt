Alpha-API-Key-Only-Four-Features.zip

تم الحفاظ على جميع ملفات النسخة الأساس. لم يتم حذف أي ملف أو تغيير أسماء المسارات. التعديلات البرمجية محصورة في إصلاحات الأخطاء التي ظهرت في المراجعة، مع اختبارات انحدار إضافية.

1) إصلاح يمنع تشغيل التطبيق
---------------------------

- الدالة تفحص ملفات Python وJSON وHTML فحصاً ساكناً فقط.
- تتحقق من المسارات الممنوعة، والتكرار، والملفات الثنائية، وحدود أحجام الملفات.
- لا تستورد ولا تشغّل أي كود مرفوع.

2) حماية ZIP والملفات المرفوعة
-----------------------------
- استثناء ملفات .env الحساسة، وملفات مفاتيح SSH، وملفات الشهادات والمفاتيح، وملفات بيانات الاعتماد.
- استثناء مجلدات .aws و.ssh و.gnupg و.config وsecrets وprivate وcredentials من تحليل المشروع أو حفظ Checkpoint.
- حماية قارئ ZIP في الشات من المسارات غير الآمنة، والروابط الرمزية، والملفات المشفرة، والملفات ذات نسب الضغط غير الآمنة، والملفات الثنائية.
- توسيع مرشحات الملفات الحساسة في فحص المشروع وتطبيق Diff ونقاط الاستعادة.

3) حماية المصادقة والطلبات
-------------------------
- إضافة CSRF token لنماذج تسجيل الدخول وإنشاء الحساب.
- حماية طلبات POST/PUT/PATCH/DELETE للمستخدمين المسجلين والمشرف عبر رمز CSRF في ترويسة X-CSRF-Token.
- إضافة رمز CSRF إلى واجهتي الشات ولوحة المشرف، وإرفاقه تلقائياً بطلبات same-origin غير الآمنة.
- تحويل تسجيل الخروج من GET إلى POST مع التحقق من CSRF.
- إضافة تحديد لمحاولات تسجيل الدخول الفاشلة: 5 محاولات خلال 15 دقيقة لكل عنوان/اسم مستخدم، وتخزين العدّاد في قاعدة البيانات ليعمل عبر أكثر من عامل تشغيل.
- إضافة تحقق خادمي من تطابق كلمة المرور وتأكيدها أثناء التسجيل.

4) حماية ذاكرة المشروع
----------------------
- استثناء مجلدات بيانات الاعتماد والمفاتيح الخاصة من تحليل المشروع.
- توسيع تنقية الذاكرة لتشمل كتل المفاتيح الخاصة ومفاتيح AWS وأنماط رموز إضافية.
- توسيع قائمة الملفات المحظورة في Checkpoint.

التحقق المنفذ
-------------
- 61 اختبار Python ناجحاً عبر unittest.
- py_compile ناجح لكل ملفات Python وملفات الاختبار.
- node --check ناجح لكتل JavaScript الثلاث بعد استبدال تعبيرات Jinja مؤقتاً بقيم صالحة للفحص.
- HTMLParser اجتاز قوالب LOGIN_HTML وADMIN_HTML وCHAT_HTML.
- تم التحقق من وجود رمز CSRF في نماذج الدخول والتسجيل والإدارة، وفي صفحات الشات والإدارة.

قيود لم يمكن اختبارها في بيئة الفحص
-----------------------------------
- لم يمكن تشغيل Flask أو اختبار HTTP فعلياً لأن Flask وgoogle-genai وpsycopg غير مثبتة، ومحاولة تثبيتها تعذرت لعدم توفر اتصال الشبكة في بيئة الفحص.
- لم يتم اختبار اتصال حي مع TokenHarbor أو قاعدة PostgreSQL أو Render.
- لم يتم إجراء اختبار بصري عبر متصفح حقيقي على Android؛ فحص JavaScript وHTML ساكن ولا يثبت شكل الحركة على كل جهاز.
- الفحص التلقائي للكود ما زال فحصاً ساكناً، ولا يشغّل ملفات المستخدم. تشغيل اختبارات المشاريع يتطلب Sandbox معزولاً منفصلاً.
